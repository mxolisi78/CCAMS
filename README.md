# 🏥 CCAMS - Campus Clinic Appointment Management System

A comprehensive desktop application developed for **Sol Plaatje University** to automate the clinic appointment booking process, replacing the manual email-based system.

---

## 📋 Features

### 🔐 Authentication
- Login with username/student number/email
- Role-based access (Admin, Nurse, Psychologist, Student)
- Password security with SHA-256 hashing
- Show/Hide password toggle
- Placeholder guidance for fields

### 👨‍🎓 Student Management
- Register new students
- View all students
- Search students by name/number/email
- Update student profiles
- Delete students (soft delete)
- Date picker for Date of Birth

### 👨‍⚕️ Staff Management
- Add Nurses and Psychologists
- View all staff
- Search staff members
- Update staff profiles
- Delete staff (soft delete)
- Filter by profession

### 📅 Appointment Management
- Book appointments
- View all appointments
- Approve appointments
- Complete appointments
- Cancel appointments
- Reschedule appointments
- Filter by status
- Date picker with calendar

### 🕐 Schedule Management
- Add staff schedules
- View all schedules
- Update schedules
- Delete schedules
- Filter by staff member
- Date picker with calendar

### 📊 Reports
- Summary Report
- Appointment Summary Report
- Weekly Report
- Monthly Report
- Annual Report
- Student Report
- Staff Report
- JasperReports integration

### ⚙️ Settings
- Clinic information
- Appointment configuration
- Notification settings
- Security settings
- Backup and restore
